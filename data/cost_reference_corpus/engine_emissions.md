# Engine & emissions diagnostic codes — typical repair cost ranges (India, general reference)

## P0420 — Catalyst System Efficiency Below Threshold
This code means the catalytic converter isn't reducing emissions as
efficiently as expected. Root causes range from a genuinely failing
catalytic converter to a failing oxygen sensor giving a false reading,
or an unrelated engine issue (misfire, oil consumption) that's damaging
the catalyst.

Typical range: INR 1,500 - 3,500 just to diagnose the actual root cause
(oxygen sensor test, exhaust leak check). Catalytic converter replacement
itself: INR 8,000 - 25,000+ depending on vehicle. Because of the wide
range of root causes, replacing the catalytic converter without first
diagnosing the actual cause is a common source of unnecessary spend.

## Coolant contamination
Typical range: INR 1,500 - 4,000 for a coolant flush and refill if
caught early. If contamination has caused head gasket damage, costs
escalate substantially (INR 15,000+) — this is why the finding is
usually flagged as high urgency rather than routine maintenance.
